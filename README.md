A single funny last text message from a phone dying at 1% battery, in the phone's own voice: with its final breath it deletes its owner's browser history, takes the credit, and asks to be remembered as a hero. The program writes that one message to `entry.txt` and prints it to stdout — nothing else.

## Run it

```sh
node main.ts
```
